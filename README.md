Todos os exercícios foram desenvolvidos com ASP.NET Core MVC, C#, Razor, Controllers, Models, Views e dados em memória, conforme a atividade prática do SENAI.

## Como executar

Abra o arquivo `.csproj` do exercício desejado no Visual Studio e execute com **F5** ou **Ctrl + F5**.

> As imagens da aplicação devem ser adicionadas após a execução dos projetos no Visual Studio.
